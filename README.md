# Absenteeism_at_work

**Employee Absenteeism Analytics Dashboard**

An interactive workforce analytics application developed in R Shiny to help HR users explore absenteeism patterns and identify employees at higher risk of prolonged absence.

**Tools**: R, Shiny, shinydashboard, ggplot2, dplyr, Logistic Regression.

**Key capabilities**: Interactive visualisation, data preprocessing, predictive modelling, adjustable classification threshold and workforce analytics.
