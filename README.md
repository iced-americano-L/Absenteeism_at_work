# Employee Absenteeism Analytics Dashboard

An interactive workforce analytics dashboard developed using **R, Shiny and Flexdashboard** to analyse employee absenteeism patterns and support data-driven workforce decision-making.

## Project Overview

This project analyses workplace absenteeism data to identify factors associated with higher levels of employee absence. The dashboard transforms workforce data into interactive visualisations and predictive insights, allowing users to explore absenteeism patterns across employee, behavioural and workplace characteristics.

## Key Features

* Interactive exploration of employee absenteeism patterns and contributing factors
* Data cleaning and preprocessing, including identification and removal of duplicate records
* Dynamic visualisations for workforce and absenteeism analysis
* Logistic regression modelling to classify **high and low absenteeism**
* Adjustable classification threshold for exploring model performance and prediction outcomes
* Interactive dashboard interface developed for non-technical users

## Technologies

**R | Shiny | Flexdashboard | ggplot2 | dplyr | Logistic Regression**

## Business Application

The dashboard demonstrates how workforce data can be transformed into actionable information to support **HR analytics and workforce decision-making**. It provides an example of using analytics and interactive information systems to connect data analysis with a practical business problem.
